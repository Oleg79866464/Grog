## Brand position
**Grog** — премиальный каталог AI-инструментов для маркетинга, SEO, SMM, контента и digital-команд.

## Recommended naming strategy
- **Brand:** Grog
- **SEO title formula:** `Grog — [ключевой запрос] | [ценность]`
- **Description formula:** `Краткое описание + аудитория + коммерческая ценность + trust signal`

## 4) Admin page

### Meta recommendation
- `noindex, nofollow`
- canonical not required for indexing

### Reason
Админка не должна индексироваться поисковыми системами.

---

## 5) Redirect route `/go/[id]`

### Meta / indexing
- `noindex`
- no sitemap inclusion
- never canonical as public content page

### Reason
Это технический tracking route, а не контентная страница.

## 7) Social / OG rules

### OG title style
- shorter than the page title
- premium and brand-focused

### OG description style
- highlight value and trust
- avoid keyword stuffing
- mention that it is a curated directory

### OG image recommendations
- dark premium background
- large bold title
- subtle gradient
- brand name `Grog`
- one strong promise line

---

## 8) Canonical rules
- every public page must have a self-referencing canonical
- canonical must use the production domain
- avoid localhost or preview domain in final metadata

---

## 9) hreflang rules
- use `ru-RU` for all public pages
- keep canonical and hreflang on the same production domain
- no conflicting language targets unless multi-language support is реально enabled

---

## 12) Final recommendation
**Keep the brand name `Grog`.**
Use SEO in titles, descriptions, schema, internal linking and content blocks — not by renaming the brand into a generic keyword phrase.

This gives the best balance of:
- brand value
- trust
- CTR
- scalability
- SEO performance
