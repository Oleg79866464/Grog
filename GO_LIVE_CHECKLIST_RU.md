# Grog — Go-Live Checklist

## Перед стартом
- [ ] Домен подключён.
- [ ] Supabase проект создан.
- [ ] Все env vars заполнены.
- [ ] Доступ к админке ограничен.
- [ ] Файлы релизного пакета открыты.

## База данных
- [ ] Применён `supabase-schema.sql`.
- [ ] Применён `supabase-ops.sql`.
- [ ] Применён `supabase-site-controls.sql`.
- [ ] Созданы таблицы `tools` и `clicks`.
- [ ] Создан view `tools_analytics`.
- [ ] Проверены RLS policies.

## Импорт данных
- [ ] Запущен `import-parser.js`.
- [ ] Проверен `ai-tools-clean.json`.
- [ ] Загружены инструменты в Supabase.
- [ ] Проверены slug, pricing, category, tags.

## Приложение
- [ ] Пройден `npm run build`.
- [ ] Пройден `npm run typecheck`.
- [ ] Главная страница открывается.
- [ ] Страницы категорий открываются.
- [ ] Страницы инструментов открываются.
- [ ] `/go/[id]` делает редирект и пишет клик.
- [ ] `/admin` защищён и показывает метрики.

## SEO
- [ ] `/robots.txt` доступен.
- [ ] `/sitemap.xml` доступен.
- [ ] canonical указывает на домен.
- [ ] hreflang настроен на `ru-RU`.
- [ ] Schema.org присутствует.
- [ ] Open Graph и Twitter cards заполнены.

## Монетизация
- [ ] Affiliate URL скрыты от UI.
- [ ] Все CTA ведут через `/go/[id]`.
- [ ] Click tracking работает server-side.
- [ ] Метрики в админке совпадают с логами.

## Перед публикацией
- [ ] Проверить мобильную версию.
- [ ] Проверить скорость загрузки.
- [ ] Проверить 404/ошибки.
- [ ] Проверить редиректы.
- [ ] Сделать финальный backup.

## После публикации
- [ ] Добавить сайт в Google Search Console.
- [ ] Отправить sitemap.
- [ ] Проверить индексацию.
- [ ] Проверить клики и доход.
- [ ] Мониторить ошибки в логах.

## Go / No-Go
- [ ] Go-live разрешён.
- [ ] Все критические пункты закрыты.
