# Grog — Post-Launch Monitoring

## Первые 10 минут
- [ ] Открыть главную страницу `/`.
- [ ] Проверить `/robots.txt`.
- [ ] Проверить `/sitemap.xml`.
- [ ] Проверить `/admin`.
- [ ] Проверить `/go/[id]`.

## Первые 2 часа
- [ ] Убедиться, что `/go/[id]` отдаёт 302 redirect.
- [ ] Проверить, что клики пишутся в Supabase `clicks`.
- [ ] Проверить, что `tools_analytics` обновляется.
- [ ] Сверить canonical URLs.
- [ ] Сверить `hreflang` на `ru-RU`.

## Первые 24 часа
- [ ] Проверить CTR карточек на главной.
- [ ] Проверить CTR на страницах категорий.
- [ ] Проверить CTR на страницах инструментов.
- [ ] Проверить top tools в админке.
- [ ] Проверить revenue per click.
- [ ] Проверить ошибки в логах.

## Первые 7 дней
- [ ] Сравнить категории по трафику.
- [ ] Найти инструменты с лучшим revenue per click.
- [ ] Обновить слабые title/description.
- [ ] Улучшить CTA на самых посещаемых страницах.
- [ ] Добавить новые внутренние ссылки.
- [ ] Проверить ранжирование в Search Console.

## Что считать тревожным сигналом
- [ ] 0 кликов при наличии трафика.
- [ ] `/go/[id]` не пишет в `clicks`.
- [ ] `/admin` открывается без логина.
- [ ] `/robots.txt` или `/sitemap.xml` недоступны.
- [ ] canonical указывает не на домен.
- [ ] sitemap не попадает в индексацию.

## Что делать при проблеме
1. Проверить окружение и env vars.
2. Проверить Supabase policies и view.
3. Проверить auth и middleware.
4. Проверить route handlers.
5. Повторно прогнать build/typecheck.

## Итог
Эта карта контроля нужна, чтобы не потерять клики, индексацию и revenue в первые дни после запуска.
