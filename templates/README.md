# templates

Папка для хранения шаблонов сайта, preview-материалов, HTML-макетов, изображений интерфейса и будущих дизайн-референсов.

## Рекомендованная структура
- `templates/ui/` — UI-макеты и скриншоты страниц
- `templates/html/` — standalone HTML-превью и релизные шаблоны
- `templates/images/` — изображения, баннеры, мокапы
- `templates/docs/` — вспомогательные шаблоны и текстовые заготовки

Файлы в этой папке можно использовать для:
- сравнения дизайна с кодом;
- хранения картинок из Midjourney/Figma;
- подготовки релизных и buyer-facing материалов;
- быстрых визуальных ревью.
