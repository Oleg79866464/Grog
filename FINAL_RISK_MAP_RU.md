# Grog — Final Risk Map

## Критические риски
- [ ] Проверить, что `/admin` защищён и не открыт публично.
- [ ] Проверить, что `/go/[id]` пишет клики в Supabase.
- [ ] Проверить, что sitemap реально доступен по `/sitemap.xml`.
- [ ] Проверить, что canonical указывает на правильный домен.

## Высокие риски
- [ ] Проверить, что data layer действительно идёт из Supabase.
- [ ] Проверить, что импорт не ломает slug и category normalization.
- [ ] Проверить, что metadata на всех публичных страницах заполнена.
- [ ] Проверить, что robots не закрывает важные страницы.

## Средние риски
- [ ] Проверить качество JSON-LD.
- [ ] Проверить корректность hreflang.
- [ ] Проверить индексацию новых страниц.
- [ ] Проверить адекватность SEO title/description.

## Низкие риски
- [ ] Проверить форматирование документов.
- [ ] Проверить актуальность текста в README.
- [ ] Проверить единообразие названий файлов.

## Статус
- Инфраструктура: требует финальной верификации.
- SEO: почти готово, нужен production check.
- Монетизация: готова к проверке через реальные клики.
- Документация: завершена.

## Итоговый вывод
Если все критические риски закрыты, проект можно считать готовым к релизу.
